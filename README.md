# MTC AG Church Website

More Than Conquerors Assemblies of God Church Website

## Tech Stack

- **Framework:** Next.js 16 with App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Components:** shadcn/ui (to be added)
- **Hosting:** Vercel
- **CMS:** Google Sheets API

## Brand Colors

- Primary Red: `#f73c4a`
- Light Neutral: `#f5f4f2`
- Dark Gray: `#353533`
- Yellow/Gold: `#efe10f`

## Development

Install dependencies: `npm install`
Run development server: `npm run dev`
Build for production: `npm run build`

## Project Structure

app/ - Next.js app directory
components/ - Reusable React components
lib/ - Utility functions
public/ - Static assets

## Build Phases

- Phase 1: Foundation & Infrastructure (DONE)
- Phase 2: Core Design System
- Phase 3: Static Homepage
- Phase 4: Other Static Pages
- Phase 5: External Integrations
- Phase 6: Google Sheets CMS
- Phase 7: Polish & Deployment
